# MonaBowling レーン建築寸法（Phase 6）

すぐ建築できるファイルは
[`schematics/README.md`](../schematics/README.md) にあります。Litematica用
`.litematic` とWorldEdit/FAWE用 `.schem` の両方を収録しています。

Minecraftの1ブロックを1mとして扱います。スタンダードと100ピンを同じレーンで
遊べる、Phase 6既定設定向けの寸法です。かべよけも同じ通常レーン内へ一時壁を表示します。

## 寸法表

| 項目 | 物理上の値 | 建築推奨 |
|---|---:|---:|
| 投球線から先頭ピン中心 | 18.00m | 18ブロック |
| 100ピン最終列中心 | 投球線から23.179m | 約23.2ブロック |
| 隠しスイッチ判定 | 投球線から23.829m | 約23.8ブロック |
| シミュレーション有効長 | 投球線から25.179m | 26ブロック以上 |
| 100ピン最外列の中心幅 | 5.52m | 中心から左右2.76ブロック |
| レーン面の物理幅 | 6.00m | 中央7ブロック |
| 左右ガター込み物理幅 | 6.80m | 9ブロックの内幅 |
| シークレット用塀上ライン | 左右3.22～3.29m | 中心から約3.25ブロック |
| 天井 | 物理制限なし | 6ブロック以上の空間 |

100本を置くためのブロックやArmorStandは不要です。先頭ピン位置だけ登録すると、
残り99本はプラグインが0.46m間隔のサブブロック座標へ表示します。標準10ピンは
0.52m間隔です。ピンは幅0.26 × 高さ0.78ブロックで表示されます。

## 1レーンの推奨外寸

- 内側：幅9 × 長さ31 × 高さ6ブロック
- 壁込み：幅11 × 長さ32～33 × 高さ7～8ブロック
- 投球線より手前のアプローチ：5ブロック
- 投球線から先頭ピン：18ブロック
- 先頭ピンから100ピン最終列：5.179ブロック
- 最終列から奥壁：4ブロック以上

最低限なら幅9 × 長さ28 × 高さ5でも収まりますが、視点、演出、後方ピット、
保守通路を考えると推奨寸法を使ってください。

## 上面図

```text
                 幅9ブロック（内側）
        ┌─────────────────────────┐
 z=-5   │       アプローチ 5       │
        │ G │   レーン7   │ G     │  G = ガター/ガード
 z=0    ├───┼────投球線────┼───┤  プレイヤー位置・中心 x=0
        │   │             │       │
        │   │  18ブロック │       │
 z=18   │   │      ●      │       │  先頭ピン
        │   │    ● ●      │       │
        │   │   100本     │       │
 z=23.2 │   │ 最終列中心  │       │
 z=23.8 │◆  │             │  ◆    │  隠しスイッチ判定
        │       後方ピット         │
 z=25+  └────────奥壁────────┘
```

中央7ブロックをレーン面、左右1ブロックずつをガターとして作ると、物理幅を安全に
覆えます。中心線から左右約3.25ブロックを塀上のシークレット経路に合わせます。
塀のレーン側はバンパー、塀上の約0.07m幅だけが通過経路、その内外は塀下の
ハーフブロックへ落ちるガターとして物理計算されます。奥の判定位置には小さな赤い
スイッチ表示が左右に出ます。

## 複数レーン

レーン中心同士を10ブロック離し、間に1ブロックの仕切りを入れます。外壁込み幅は
`10 × レーン数 + 1`ブロックが目安です。

| レーン数 | 推奨外幅 |
|---:|---:|
| 1 | 11ブロック |
| 2 | 21ブロック |
| 3 | 31ブロック |
| 4 | 41ブロック |

## 座標登録

1. 床をすべて同じ高さにします。
2. 投球線中央に立ち、レーン奥へ東西南北のいずれかへ正確に向きます。
3. `/bowling admin create lane01` を実行します。先頭ピンは自動で18m先になります。
4. 同じ位置で `/bowling admin setlane lane01` と
   `/bowling admin setspawn lane01` を実行します。
5. 中央線上を18ブロック進み、先頭ピン中心で
   `/bowling admin setpins lane01` を実行します。
6. `/bowling admin debug` でレーン数を確認します。
7. `/bowling join standard lane01` と
   `/bowling join hundred-pin lane01` をそれぞれ試します。

`setspawn`と`setpins`はプレイヤーの足元Y座標を保存します。床の高さを変えず、
両地点のYを一致させてください。斜め向きでも動きますが、建築と座標確認が難しくなる
ため、東西南北の直線レーンを推奨します。
