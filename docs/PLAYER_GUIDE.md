# MonaBowling プレイヤーガイド（Phase 6 + 4人対戦）

スタンダード、100ピン、かべよけを、1レーン最大4人でプレイできます。

- `/bowmenu` — モード、レーン、人数、公開ロビー、戦績をGUIで操作
- `/bowling` — メニューと現在の段階を表示
- `/bowling join [レーンID]` — スタンダードへ参加
- `/bowling join hundred-pin [レーンID]` — 100ピンへ参加
- `/bowling join wall-dodge [レーンID]` — かべよけへ参加
- `/bowling leave` — 途中退出
- `/bowling client` — Java/統合版、入力方式、感度の診断
- `/bowling stats [mode]` — モード別戦績を表示
- `/bowling top [mode]` — モード別ランキングを表示
- `/bowling help` — コマンド一覧を表示

## 投げ方

1. 参加すると専用の「ボウリングボール」が選択されます。
2. A/Dキー、左スティック、タッチ操作で左右の立ち位置を決めます。
3. 視点を動かし、ガイド線をピンへ合わせて投球方向を決めます。
4. Java版は右クリック、統合版は「使用」または「攻撃」で構えると投球ゲージが始まります。
5. 構えている間に視点を左右へ動かすとカーブ量が変わります。
6. もう一度入力すると通常投球します。最大まで溜めると自動で投球します。
7. ピンが停止すると倒ピン数が確定し、ピンセッター後に次の投球へ進みます。

## Shiftカーブ投球

1. 通常どおり右クリック（統合版は使用・攻撃）で構えます。
2. 構えている間に視点を動かすと、曲げたい左右方向を指定できます。
3. 投げたい強さのタイミングでShift（統合版はスニーク）を押します。
4. Shiftを押した瞬間に投球し、遅いタイミングほど回転が強くなります。

視点を動かさずShift投球した場合は、現在の立ち位置からレーン中央へ食い込む方向へ
自動で曲がります。通常の2回目クリックは従来どおり使用でき、Shiftを使わなければ
強制カーブは付きません。

`/bowling admin setspawn` で設定された投球線がファウルラインです。
ゲーム中はこの線よりピン側へ進めませんが、線の後ろでは左右に移動できます。

スタンダードと100ピンの両方で左右の壁がバンパーになり、
当たったボールは少し減速してレーン内へ跳ね返ります。

正式な10フレーム採点、ストライク、スペア、ダブル、ターキー、スプリット、
最終フレームの追加投球に対応します。100ピンでは1投最大100点、パーフェクトは
3000点です。100ピンでは通常レーン側から塀へ当たるとバンパーとして跳ね返ります。
塀の上にあるごく細い線へ投球開始時から正確に乗せ、そのまま奥の赤いスイッチまで
通した場合だけシークレットストライクになります。塀の上から外れると、下の
ハーフブロック部分へ落ちたものとしてガターになります。

## かべよけ

通常の10ピン・10フレーム採点で遊びます。フレームが進むごとにレーン上の壁が増え、
開いているコースへ立ち位置・方向・カーブを合わせて投球します。壁へ当たると金属音と
ともに球が減速して反射します。左右のガターには通常どおり落ちます。

壁はJava専用表示ではなくサーバーの実ブロックとして一時表示されるため、統合版でも
同じ場所・同じ形で見えます。ゲーム終了や異常終了時には自動的に元の空気へ戻ります。

## 2〜4人で遊ぶ

1. `/bowmenu` を開き、モードと空きレーンを選びます。
2. 「人数」を2〜4人に設定して公開ロビーを作ります。
3. 他のプレイヤーは `/bowmenu` の「公開ロビー一覧」から参加します。
4. 設定人数に達すると自動開始します。作成者は途中の人数でも開始できます。
5. 各プレイヤーは1フレーム分を投げ終えると次の人へ交代します。
6. 順番待ちの人は投球線の後ろで観戦します。スコアと残存ピンは参加者別です。

募集中はチャットを繰り返さず、画面上部のBossBarにレーン、参加人数、`/bowmenu`案内が
表示されます。ゲーム開始または募集終了でBossBarは自動的に消えます。

自由観戦は後続改善です。統合版ではタッチ、
コントローラー、キーボード・マウスごとに
視点感度が調整され、Java版に存在するDisplay Entityの代わりに互換表示を使用できます。
実端末で違和感がある場合は `/bowling client` の結果を管理者へ伝えてください。
