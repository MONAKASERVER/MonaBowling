# Phase 6 手動テスト計画

以下は実機Hubでのみ確認できるため、現時点では未実施です。

## 起動・停止

1. Paper 26.1.2 / Java 25で起動し、プラグインが有効になる。
2. SQLiteファイルとschema version 1が作成される。
3. 正常停止時にDB接続とI/Oスレッドが閉じる。
4. 再起動後に登録レーンが復元される。

## 管理操作

1. OPがレーンを作成・更新・削除できる。
2. 一般プレイヤーはadmin操作を実行できない。
3. 別ワールドから既存レーン座標を更新できない。
4. 不正なIDと不正なconfig値が拒否される。
5. 使用中レーンの削除・座標更新と、ゲーム中のreloadが拒否される。

## 10ピンゲーム

1. 空きレーンへ参加し、同じプレイヤーの二重参加と同じレーンの二重使用が拒否される。
2. 1回目の使用でゲージ開始、2回目でリリース、自動リリースが動作する。
3. 視点移動の左右で逆方向のスピンが付き、無操作では概ね直進する。
4. ボール、各ピン、ピン同士の衝突が実際のスナップショットに沿って描画される。
5. 左右壁でボールが減速反射し、壁抜けやガター判定にならない。
6. ストライク、スペア、ダブル、ターキー、スプリットが表示される。
7. 最終フレームのボーナス投球とパーフェクト300点を確認する。
8. 完了時にSQLiteへ10個の累積フレーム点と各カウンタが保存される。
9. 退出・死亡・キック・切断・ワールド移動・停止後にDisplayと専用ボールが残らない。
10. インベントリ操作、ドロップ、持ち替えで専用ボールを持ち出せない。
11. 構え中のShiftで即リリースされ、右・左の立ち位置から中央方向へカーブする。
12. 構え中に視点を左右へ動かした場合は、その向きがShiftカーブ方向を上書きする。
13. 早いShiftは弱い回転、ゲージ後半のShiftは強い回転となり、通常投球は維持される。

## 2〜4人対戦とメニュー

1. `/bowmenu`でモード、空きレーン、1〜4人を変更できる。
2. 2〜4人設定では公開ロビーとなり、一覧から設定人数まで参加できる。
3. 満員時は自動開始し、作成者は満員前でも開始できる。
4. 各人が1フレームを完了するたびに順番が交代し、残存ピンとスコアが混ざらない。
5. 非手番プレイヤーはボールを持てず、投球線の後方で待機する。
6. 途中退出・死亡・切断時も残りのプレイヤーで継続し、表示が重複しない。
7. Java・統合版の混在ロビーで全員にボールとピンが表示される。
8. GUIでクリック・Shiftクリック・ドラッグしてもアイテムを出し入れできない。
9. 募集中の案内がBossBarだけで更新され、2秒ごとのチャット通知が出ない。

## クロスプレイ準備

1. Java版と統合版の双方で `/bowling` が表示される。
2. Floodgateが存在する場合にdebug表示がtrueとなる。
3. コマンド候補が統合版でも操作を妨げない。
4. `/bowling client`がJavaをJAVA、Floodgate接続をBEDROCKとして判定する。
5. タッチ・ゲームパッド・キーボード入力が可能な端末でInput表示と感度を比較する。
6. 統合版ではネイティブItem Entity互換ピン・ボール、Java版ではBlockDisplayが表示される。
7. 統合版の使用と攻撃の双方で構え・リリースでき、二重パケットで即投球されない。
8. 統合版のスニーク入力でShiftカーブ投球が1回だけ発動する。
9. 179度から-179度へ視点を跨いでも最大スピンが誤発生しない。
10. Java・統合版の同時接続中に各セッションの入力設定が混線しない。

## 100ピンゲーム

1. `/bowling join hundred-pin`で100本が三角形状に表示される。
2. 100本がそれぞれ独立して衝突し、大量転倒でもTPSと描画が継続する。
3. 1フレームのストライクを100点、スペアを合計100点としてボーナス計算する。
4. 12連続ストライクで3000点となり、`hundred-pin`戦績にだけ保存される。
5. 第2投で細い塀上ラインを完走してシークレットを成立させると、スペアになり残存ピンだけが消費される。
6. ガード途中から乗せる、ガードから落ちる、左右を切り替える投球では発動しない。
7. シークレット成立時に残存ピンの崩壊演出、ストライク時にピン方向の視点演出が出る。
8. 40本以上の連鎖で演出が出ても、音とパーティクルが接触数に比例して暴走しない。
9. 100ピン同時上限を超えた参加だけが拒否され、10ピン参加は可能である。
10. Java/統合版双方で退出後に100体の表示エンティティが残らない。
11. 通常レーン側から塀へ当てると反射し、塀上ラインの内外へ外れるとガターになる。
12. 左右の塀奥に赤いシークレットスイッチが表示される。
13. 通常投球20パターンで95本以上の自動連鎖が起きず、強投では40本以上の連鎖も残る。

## かべよけ

1. `/bowmenu`でスタンダード、100ピン、かべよけの順にモードを循環できる。
2. 全10フレームで壁配置が段階的に変わり、通常10ピン採点で最大300点になる。
3. 高速球でも薄い壁をすり抜けず、衝突後に設定反発率で跳ね返る。
4. 壁に当たらない投球は通常どおりピンへ到達し、ストライク・スペアを記録できる。
5. Java版と統合版で同じ壁、球、ピンが見え、衝突位置も一致する。
6. 2〜4人戦で手番プレイヤーの現在フレームに応じた壁へ切り替わる。
7. 壁設置前の非空気ブロックは変更されず、ゲーム終了時に一時壁だけが復元される。
8. 旧`spin-control`を含む既存レーンDBがエラーなく`wall-dodge`として読み込まれる。
